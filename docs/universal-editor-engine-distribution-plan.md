# Universal Page Builder — Editor + Engine Distribution Plan

## 1. Final Goal

The final architecture must strictly separate the **editor** from the **rendering engines**.

```text
page-builder/
├── editor/
│   └── react/
├── blocks/
├── specification/
├── conformance/
├── engine/
│   ├── laravel/
│   └── golang/
├── examples/
├── scripts/
└── docs/
```

Core principles:

- React is the only editor.
- Laravel is an independent rendering engine.
- Golang is an independent rendering engine.
- Laravel is not the parent of the Golang engine.
- Golang does not depend on Laravel.
- `blocks/` is universal and is consumed by every engine.
- `specification/` is universal and is the source of truth for every engine.
- Page JSON generated by React must be identical regardless of whether Laravel or Golang renders it.
- A block must be authored once and render in both Laravel and Golang without duplicate templates.
- Engines must be distributable and runnable independently.
